Real-Time EV Battery Management System

Adaptive Multi-Cell Battery Intelligence Engine

Project Overview

This project implements a simulated real-time Battery Management System for a 4-cell lithium battery pack. The system monitors individual cell voltages, evaluates battery pack condition, calculates cell imbalance, identifies the strongest and weakest cells, and classifies the overall battery health.

Key Features

4-Cell Monitoring

Individual voltage monitoring for four battery cells.

Pack Voltage

Real-time calculation of total battery pack voltage.

Cell Imbalance

Calculation of voltage variation between cells.

Health Classification

Battery condition classification based on cell measurements.

Battery Intelligence

  • Individual cell voltage calculation
  • Average cell voltage calculation
  • Battery pack voltage calculation
  • Strongest cell identification
  • Weakest cell identification
  • Cell voltage imbalance calculation
  • Battery health state classification
  • Real-time serial monitoring

Battery Health States

  • Healthy – Battery cells are operating within acceptable balance.
  • Minor Imbalance – Small voltage variation is detected between cells.
  • Critical Imbalance – Significant voltage imbalance is detected.
  • Pack Failure – A cell voltage is outside the configured safe operating range.

Simulation & IoT Monitoring

The battery management system was developed and tested using an ESP32 simulation environment. Analog inputs represent the voltage conditions of the four battery cells.

The monitoring system is also integrated with ThingSpeak for cloud-based data transmission and dashboard visualization. Successful HTTP communication was verified during testing.
